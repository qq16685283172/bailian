# 百炼计划

基于产品系统设计稿实现的学员端、管理端与听课数据同步服务，采用 React + Vite + Express。

## 启动

```bash
npm install
npm run dev
```

该命令同时启动前端页面和定时同步服务。生产环境先执行 `npm run build`，再执行 `npm start`。

协作开发（环境要求、分支流程、发布方式）见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 登录与管理员认证

- 5 开头精网号为学员账号，无需密码，登录后隐藏管理端；只能查看当前账号的学习档案。
- 3 开头精网号为管理员账号，初始密码 `123456`，登录后进入管理端，可在侧栏修改密码。
- 会话使用 HttpOnly、SameSite=Lax Cookie，生产 HTTPS 下启用 Secure，默认 7 天有效，可通过 `AUTH_SESSION_HOURS` 调整。
- 管理接口仅允许 3 开头账号访问；学员接口校验当前会话，禁止修改 URL 查看他人档案。登录失败有频率限制。
- 修改后的密码使用 scrypt 加盐散列保存在 `server/data/auth.json`，不会明文保存；修改密码会注销该账号的其他会话。服务重启后需要重新登录。

## 听课数据同步

1. 复制 `.env.example` 为 `.env`，将 `LIVE_LIST_URL` 设置为包含有效令牌和频道 ID 的完整直播列表地址。
2. 服务每天 **12:00 与 00:00**（Asia/Shanghai）自动补查最近两天；管理端「数据同步」支持手动补查近期数据，或选择「自 2026-06-24 起」补采历史记录。
3. 「班级群定向补采」可读取真实班级列表，选择单一班级补查近期或自 2026-06-24 起的数据，并可加入每日自动同步；班级与频道共享直播 ID 去重。
4. 同步观看时长、有效评论和领航卡记录，不保存聊天正文；原始听课记录以直播 ID + 精网号去重。
5. 数据保存在 `server/data/store.json`，同步服务必须持续运行。令牌失效时在「数据同步 → 数据源凭证管理」粘贴新的完整直播列表链接，连接测试成功后保存；精网无需重启。凭证保存在 `server/data/credentials.json`，接口只返回掩码。投教当前仅支持凭证保存与测试，尚未启用自动同步。

## 自动计分与历史重算

- 仅「财经壹眼」和「易学久会」计算基础听课积分，按直播开播时间自动归类：09:00–12:00 为财经壹眼（正常 09:30 开播），19:00–24:00 为易学久会（正常 20:00 开播）；区间包含起点、不包含终点，因此 09:00 或 10:00 的早间直播均计入财经壹眼。
- 有效打卡 / 评论、观看严格超过 20 分钟、送出领航卡各加 1 分，每个栏目每天最多 3 个基础行为分。
- 只统计 **2026-06-24 及以后**的直播。同一学员、同一天、同一栏目在精网与投教的重复直播或重播合并计分，不重复入账。
- 内置「领航粉丝群 · 20点听课」活动：仅匹配精网班级 ID 3723 在 20:00–21:00 开播的班级直播，不按财经壹眼或易学久会栏目归类，也不要求匹配直播标题；有有效听课行为即加 9 分。同一学员同一天只加一次，多场班级重播不重复入账。
- 管理端「规则配置」可调整起算日期、观看阈值和礼物名称，也可新建活动固定加分，按平台、班级、栏目、直播关键词、直播时段和有效期限定范围。
- 「新建翻倍活动」支持选择财经壹眼或易学久会，自定义基础分倍数、执行开始和结束日期、适用平台及优先级；活动分不参与翻倍。多条多倍规则不连乘，按优先级取一条。
- 保存规则或点击「全量重算」会根据已同步的原始行为重新生成账本，不会重复抓取或修改原始听课记录；活动分与基础行为分分开展示。
- 规则重算只处理已经同步的数据。若需补齐 2026-06-24 以来的历史积分，请先在「数据同步」和「班级群定向补采」中分别选择「自 2026-06-24 起」完成补采。

## 真实业务数据

- 数据总览、学员管理、行为分析和运营分析均由 `students`、`dailyPoints`、`attendance`、`lives` 与同步日志实时聚合，不使用演示指标。
- 奖励由管理员在管理端真实配置，库存、上下架、领取资格和唯一领取凭证均持久化在 `server/data/store.json`；领取不消耗积分且不可重复领取。
- 学员可提交积分申诉，管理员可创建补扣分申请；审核通过后形成独立人工调整账本，并在每次历史重算时保留。
- 学员名单、排行榜、审核记录和趋势图支持导出当前真实数据。没有真实记录时显示空状态，不使用静态学员、榜单或奖励回退。

3 开头管理员登录后可在学员端与管理端之间切换；5 开头学员仅显示学员端。学员端按当前登录精网号读取真实任务、基础分、活动分、调整分、总积分、等级、明细和排行榜，每 30 秒及窗口重新聚焦时自动刷新。
